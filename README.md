# 南澳孝心慢遊行程 App

這是一個專為深圳南澳三天兩夜行程設計的輕量化 Web App。

## 🚀 如何使用

1. **直接開啟**：在手機或電腦瀏覽器中開啟 `index.html` 即可使用。
2. **部署至 GitHub Pages**：
   - 將此資料夾上傳至您的 GitHub 儲存庫 (Repository)。
   - 進入儲存庫的 **Settings** > **Pages**。
   - 在 **Build and deployment** 下選擇 `main` 分支並儲存。
   - 幾分鐘後，您將獲得一個專屬的網址，發送給家人即可在手機上像 App 一樣閱讀行程。

## ✨ 功能亮點
- **離線可用**：單一 HTML 檔案，包含所有樣式。
- **手機優先**：針對手機螢幕優化，具備底部導覽列。
- **一鍵導航**：點擊行程卡片中的導覽按鈕即可開啟地圖。
- **導遊建議**：內建景點背景與長輩慢遊攻略。
